## Official Android Support Floor
**OFFICIAL MINIMUM = API 26**
**FULL AI RECOMMENDED = API 28+** (Recommended for stability with large memory mapped models).

**Reason:** Dependency capability audit confirms 100% of the application's runtime needs (Compose, STT/MT/TTS, Coroutines, ECDH Crypto, RFCOMM Bluetooth) execute safely on API 26.
